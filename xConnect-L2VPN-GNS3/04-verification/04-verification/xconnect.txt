# xConnect Verification

## PE1

```cisco
show xconnect all
```

Expected:

```text
UP  ac Gi0/2:4(Ethernet)  UP  mpls 44.44.44.44:10  UP
```

## PE2

```cisco
show xconnect all
```

Expected:

```text
UP  ac Gi0/2:4(Ethernet)  UP  mpls 11.11.11.11:10  UP
```

## Interpretation

The xConnect has two segments:

```text
Segment 1 = Attachment Circuit
Segment 2 = MPLS Pseudowire
```

Both segments must be `UP`.

---

## CE1 to CE2

```cisco
CE1#ping 192.168.10.2
```

Expected:

```text
!!!!!
Success rate is 100 percent (5/5)
```

## CE2 to CE1

```cisco
CE2#ping 192.168.10.1
```

Expected:

```text
!!!!!
Success rate is 100 percent (5/5)
```
