# P2 — Final Configuration

## Role

Provider router.

P2 is the second MPLS core router between P1 and PE2.

## Loopback

```cisco
hostname P2

interface Loopback1
 ip address 2.2.2.2 255.255.255.255
```

## P1-facing Interface

```cisco
interface GigabitEthernet0/0
 description MPLS-CORE-to-P1
 ip address 10.10.10.10 255.255.255.252
 no shutdown
```

## PE2-facing Interface

```cisco
interface GigabitEthernet0/1
 description MPLS-CORE-to-PE2
 ip address 10.10.10.13 255.255.255.252
 no shutdown
```

The two links use separate `/30` networks:

```text
10.10.10.8/30
10.10.10.12/30
```

## OSPF

```cisco
router ospf 1
 network 10.10.10.8 0.0.0.3 area 0
 network 10.10.10.12 0.0.0.3 area 0
 network 2.2.2.2 0.0.0.0 area 0
 mpls ldp autoconfig
```

## MPLS / LDP

```cisco
mpls ldp router-id Loopback1
```

## Verification

```cisco
show ip interface brief
show ip ospf neighbor
show ip route
show mpls interfaces
show mpls ldp neighbor
show mpls forwarding-table
```

## Expected OSPF

```text
P1  = FULL
PE2 = FULL
```

## Expected LDP

```text
P1  = Oper
PE2 = Oper
```

P2 is a pure provider/core router and does not contain an xConnect configuration.
