
# P1 — Final Configuration

## Role

Provider router.

P1 is the first MPLS core router between PE1 and P2.

P1 does not have any customer-facing interface.

## Loopback

```cisco
hostname P1

interface Loopback1
 ip address 1.1.1.1 255.255.255.255
```

## PE1-facing Interface

```cisco
interface GigabitEthernet0/0
 description MPLS-CORE-to-PE1
 ip address 10.10.10.2 255.255.255.252
 no shutdown
```

## P2-facing Interface

```cisco
interface GigabitEthernet0/1
 description MPLS-CORE-to-P2
 ip address 10.10.10.9 255.255.255.252
 no shutdown
```

The `/30` masks are important.

The two links belong to different subnets:

```text
10.10.10.0/30
10.10.10.8/30
```

This avoids the interface overlap problem encountered during the lab when `/24` masks were initially used.

## OSPF

```cisco
router ospf 1
 network 10.10.10.0 0.0.0.3 area 0
 network 10.10.10.8 0.0.0.3 area 0
 network 1.1.1.1 0.0.0.0 area 0
 mpls ldp autoconfig
```

## MPLS / LDP

```cisco
mpls ldp router-id Loopback1
```

## Verification

```cisco
show ip interface brief
show ip ospf neighbor
show ip route
show mpls interfaces
show mpls ldp neighbor
show mpls forwarding-table
```

## Expected OSPF

```text
PE1 = FULL
P2  = FULL
```

## Expected LDP

```text
PE1 = Oper
P2  = Oper
```

P1 is a pure provider/core router and does not contain an xConnect configuration.
